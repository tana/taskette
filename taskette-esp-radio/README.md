# esp-radio support for for [Taskette](https://github.com/tana/taskette)

This crate is the interface library between [esp-rtos](https://crates.io/crates/esp-rtos) and [Taskette](https://github.com/tana/taskette).
It implements interface specified in (esp-radio-rtos-driver)[https://crates.io/crates/esp-radio-rtos-driver].
